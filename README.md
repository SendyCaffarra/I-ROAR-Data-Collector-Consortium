# I-ROAR-Data-Collector-Consortium

# Overview
The I-ROAR Data Collector Consortium is a collaborative group of researchers who contributed to the collection, curation of I-ROAR data. The consortium exists to formally recognize substantial, distributed contributions to large-scale data collection efforts that cannot be adequately represented through traditional authorship alone. The consortium is listed as a group author on publications arising from these data, with individual consortium members listed on this public page and linked from the manuscript.

# Purpose
The goals of the I-ROAR Data Collector Consortium are to:
- Enable large-scale, multi-site data collection, curation
- Promote transparency and fairness in authorship attribution
- Ensure reproducibility and data integrity
- Acknowledge essential contributions by data collectors/ curators

# Authorship Model
Publications using data collected by consortium members list “I-ROAR Data Collector Consortium” as a group author.
Named authors in the manuscript represent the study guarantors and writing team. Consortium members are not listed individually in the main author byline but are publicly acknowledged on this page.

# Membership Criteria
Researchers qualify for membership in the I-ROAR Data Collector Consortium if they meet all of the following criteria:
- Substantial contribution to data collection or data curation for an I-ROAR project
- Adherence to the approved study protocol, including ethical and data quality requirements

# A general contribution statement used in manuscripts is:
All members of the I-ROAR Data Collector Consortium contributed to data collection or curation.
